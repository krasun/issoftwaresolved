## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Data

Raw data lives in `data/raw/`, which is ignored by Git, cached as monthly snapshots in a private R2 bucket. Use `npm run cache:synchronize` to refresh it and `npm run cache:pull` to restore it. See `data/README.md`.

Never read R2 during a build, and never make the bucket public. `npm run cache:synchronize -- --models` spends money, so only run it when asked.
